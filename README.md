# continual-pretraining-from-scratch-teach-a-tiny-lm-a-new-domain-without-forgetting-the-old
A pretrained language model is never finished: it has to absorb new domains, new languages and newer data without losing what it already knows. This project rebuilds that problem at a scale you can run on a CPU.
